9-zip

Welcome to 9-zip. 9-zip is a free archive manager for Windows. It works like 7-Zip and adds its own self-healing .9z format.

The 9-zip window

The window lists the files and folders of one folder, or the contents of an open archive.

  • Open a folder or archive: double-click it, or type its path in the address box and press Enter.
  • Go up one level: click the arrow left of the address box, or press Backspace.
  • Open a file: double-click it. A file inside an archive is extracted to a temporary folder and opened in its usual program.
  • Select several items: Ctrl+click to add one item, Shift+click to select a range.
  • Copy items out: drag them into File Explorer, or use Copy (F5).
  • Column widths: drag the edge of a column heading. 9-zip remembers the widths.

Toolbar: Add, Extract, Test, Copy, Move, Delete (to the Recycle Bin) and Info (Windows Properties).

Favorites: Desktop, Documents, Downloads and drive C:\ are always there. Use Add or Remove This Folder for your own.

Adding files to an archive

  1. Select the files and folders.
  2. Click Add.
  3. Choose the archive name, the format, the compression level and, for .9z, the recovery data.
  4. Click OK.

Compression level: Store packs without compressing; Ultra gives the smallest archive but takes longest. Normal is a good balance.

CPU threads: more threads pack faster on modern processors.

If an archive with the same name already exists, 9-zip asks before replacing it.

Extracting and testing

Extract: select an archive (or open it), click Extract, choose a folder and click OK. Tick Overwrite existing files only when you want files with the same names replaced.

Extract only some files: open the archive, select the files and press F5 (Copy), or drag them into File Explorer.

Test: select or open an archive and click Test. 9-zip reads every file to the end and checks it, without writing anything. "There are no errors" means every check passed.

How well damage is found depends on the format: .9z checks every file and every block, ZIP and 7Z check every file, and plain TAR and BROTLI have no checksums at all.

Explorer right-click menu

Right-click files or folders in File Explorer and open the 9-zip submenu:

  • Add to archive... opens the Add to Archive window.
  • Add to "name.9z" and Add to "name.zip" pack straight away, next to the selected items.
  • Extract here, Extract to "name\" and Test archive appear on archives.

Only the needed window appears, and 9-zip closes when it has finished. Existing files are never replaced by Extract here.

Double-clicking a .9z file opens it in 9-zip.

The .9z format

.9z is the archive format of 9-zip. It brings three features together.

Self-healing

A .9z archive carries Reed-Solomon recovery data. When parts of the archive are damaged, for example by bad disk sectors or a broken download, 9-zip rebuilds them automatically while extracting. Test reports how many damaged blocks it found and can rebuild.

You choose the amount of recovery data in the Add to Archive window:

  • Low: 5% extra size
  • Normal: 10% extra size (recommended)
  • High: 20% extra size, for the strongest repair

Recovery blocks are spread out, so even one long damaged stretch can be repaired: up to about 1 MB in every 10 MB at Normal. The archive header and its block list are each stored twice.

Smart-adaptive compression

Text, code and documents are packed together with LZMA2, the method 7z uses, for a small archive. Photos, videos and other files that are already compressed are stored as they are, so no time is spent trying to shrink them.

VSA Integrity Seal

Every file in a .9z archive carries a SHA-256 fingerprint. Testing or extracting checks every file against it, so damage never goes unnoticed.

People you send a .9z archive to need 9-zip to open it. Use ZIP when the other person may not have 9-zip.

Passwords and encryption

ZIP and 7Z archives can be protected with AES-256. In the Add to Archive window, type the password twice, or tick Show password to type it once while seeing it.

  • ZIP: the contents are encrypted, but the list of file names stays visible. This is how ZIP works in every program.
  • 7Z: tick Encrypt file names to hide the list as well.

When an archive needs a password, 9-zip asks for it and remembers it until you close 9-zip.

Keep your password safe: nobody, including the makers of 9-zip, can recover files from an archive whose password is lost.

.9z and the TAR-based formats do not offer encryption.

Frequently asked questions

Why is a .9z archive a little larger than a .7z archive?
Because it carries recovery data (5%, 10% or 20%). That extra data is what lets 9-zip repair damage. Choose Low for the smallest archive.

Can other programs open .9z?
No. Recipients need 9-zip, which is free. For people without 9-zip, use ZIP.

Does 9-zip collect any data?
No. 9-zip does not connect to the internet and collects nothing.

9-zip says an archive is damaged too badly to repair.
More blocks were damaged than its recovery data can rebuild. Files in undamaged parts can usually still be extracted by selecting them.
